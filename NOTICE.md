# Source provenance

`skills/browser-cdp` was imported from the maintainer's existing local browser-cdp skill (upstream V36). The imported copy excludes registry-generated signatures/manifests and runtime data. Internal account metadata and company-specific example domains were removed. A data-handling section clarifies the existing implementation's behavior; browser functionality was preserved.

Skillhub's browser-cdp version starts at `1.0.0`; it is independent of the upstream registry's V36 version label. Future changes are maintained in this Git repository.

This repository is private and has no open-source license grant. Package metadata uses `UNLICENSED`. Public redistribution and any licensing decision require a separate decision by the owner.
